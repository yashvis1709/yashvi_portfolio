# Space Engineering Student Portfolio

A responsive 3-page HTML portfolio for a second-year space engineering student.

## Pages
- `index.html` — profile, skills, selected projects, student journey
- `projects.html` — scalable project portfolio grid
- `contact.html` — public contact details and demo contact form

## Customize
Search and replace these placeholders:
- `Ava Patel`
- `Toronto, Canada`
- `ava.student@example.com`
- LinkedIn and GitHub URLs
- Project titles, descriptions, technology tags, and links

## Add more projects
In `projects.html`, duplicate any `<article class="project-card">...</article>` block and update its content. The grid automatically expands.

## Hosting
This is a static site and can be hosted on GitHub Pages, AWS S3 + CloudFront, Netlify, Vercel, Azure Static Web Apps, or any standard web server.

## Contact form
The supplied form is front-end only. Connect it to Formspree, Netlify Forms, an API endpoint, or another form backend before going live.
